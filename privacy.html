Privacy Policy

Last updated: 22 October 2026

BoltGallery is a Windows photo library designed to help you browse and organise access to photos stored on your PC. This policy describes the app behaviour documented in the current project README. Update this policy if the released app's behaviour changes.

1. Photos and files

BoltGallery scans supported image files on your device and builds a local index to display them. The app is designed to be read-only and does not modify or delete your original photos. Cloud-only OneDrive placeholders are skipped so the scan does not trigger their download.

2. Local storage

The app stores its index, thumbnail cache, settings and optional people/location data in your Windows local application data folder, under %LOCALAPPDATA%\\Lumen in the current implementation. These files support faster subsequent launches and app features.

3. People and face grouping

If you use the People feature, the app downloads face-analysis model files the first time they are needed. Face detection and grouping then run on your device, using DirectML/GPU where available or the CPU otherwise. The project documentation states that photos, face data and names stay on your PC.

4. Location information and third-party service

The Locations feature reads GPS metadata embedded in supported photos and groups nearby photos locally. To display human-readable place names, the app may send location coordinates to OpenStreetMap's Nominatim geocoding service. Looked-up names are cached locally. If the app is offline or a name is not available, the app can display coordinates instead.

When you use this feature, the third-party service's own privacy terms may apply. Review the OpenStreetMap Foundation's privacy information before relying on this feature.

5. Network access

According to the project documentation, location naming is the feature that uses an online service. The People feature downloads model files once before local processing. Confirm the final release's network behaviour before publishing this policy.

6. Children and advertising

BoltGallery is a general-purpose photo utility. This policy does not describe any advertising, analytics, account, or telemetry service because none is documented in the supplied project README. If any such service is added, update this policy to describe it accurately.

7. Your choices

You can stop using the app at any time. The app's local data folder can be removed to reset its cached library and feature data, but close BoltGallery first. Removing cached data does not delete your original photo files.

9. Changes to this policy
